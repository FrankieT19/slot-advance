# slot. advance v1.1

- Reworked the GBA in-game menu with the DS Style font and a cleaner layout.
- Consistent controls for GBA Addon, GB and GBC games: **Start + Select** opens the in-game menu; **hold Select for three seconds** to return to the carousel.
- Returning from a game ejects its cartridge with slot.'s animation and sound.
- GB/GBC games run without SGB borders and fade smoothly through black when exiting.
